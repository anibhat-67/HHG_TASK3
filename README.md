# Face Identification and Blockchain Ledger System

## Overview
This repository contains a robust, end-to-end pipeline that detects human faces in an image, identifies the individuals using reverse image search, and securely logs the findings on a cryptographic blockchain ledger. It is designed to handle both individual portraits and complex group photos, processing each detected face independently.

## Architecture and Workflow

The system is composed of three primary modules that execute sequentially:

1. **Face Detection and Encoding (`face_process.py`)**
   - Utilizes the InsightFace library (with the `buffalo_l` model) for high-accuracy face detection.
   - Extracts 512-dimensional facial embeddings, estimates gender, and approximates age.
   - Computes a detection confidence score for each face.
   - Automatically crops each detected face with appropriate padding and saves them as independent image files for downstream processing.
   - Outputs intermediate results to a local JSON file (`face_data.json`).

2. **Reverse Image Search and Identification (`reverse_search.py`)**
   - Integrates with the SerpApi platform to perform Google Lens reverse image searches.
   - Employs a dual-layered identification strategy:
     - **Primary:** Attempts to extract verified identities via Google's Knowledge Graph.
     - **Secondary (Fallback):** If the Knowledge Graph yields no results, the system aggregates the titles of the top 59 visual matches, performs frequency analysis to determine the most statistically probable name, and executes a targeted search to locate the subject's official digital footprint (e.g., Wikipedia, LinkedIn, X/Twitter).
   - Skips e-commerce and stock photo domains to ensure high-quality social media or encyclopedic links are retrieved.

3. **Cryptographic Verification (`blockchain_verify.py`)**
   - Implements a local, persistent blockchain ledger.
   - For every successfully identified face, the system generates a SHA-256 hash of the target URL.
   - A new block is appended to the ledger containing the subject's name, the discovered URL, the face detection confidence score, and a timestamp.
   - Ensures chain integrity through continuous verification of previous block hashes.

## Prerequisites

- Python 3.8 or higher
- C++ Build Tools (required for InsightFace compilation on Windows)
- A valid SerpApi key

## Installation

1. Clone the repository and navigate to the project directory.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Create a `.env` file in the root directory and add your SerpApi key:
   ```env
   SERPAPI_KEY=your_api_key_here
   ```

## Usage

To execute the pipeline, run `main.py` and provide the path to an input image:

```bash
python main.py input/your_image.jpg
```

If no arguments are provided, the system will default to processing `input/test2.jpeg`.

## Output Structure

The system generates the following outputs in the `output/` directory:
- `crops/`: Individual cropped images of each detected face.
- `face_data.json`: Metadata generated by the InsightFace module.
- `discovered_url.txt` and `discovered_name.txt`: Temporary files caching the most recent search results.
- `blockchain.json`: The persistent ledger storing the cryptographic history of all identified subjects.

## Limitations

The reverse image search relies on Google Lens and publicly indexed web data. It performs optimally on public figures, officials, or individuals with a significant, publicly accessible digital presence. It is generally unable to identify private individuals lacking an indexed photographic footprint.
